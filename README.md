# Train Journey Management System

## Overview

This repository contains a Python implementation of a train journey management system inspired by a railway bogie management challenge.

The application processes train bogie information, filters completed journeys at Hyderabad Junction (HYB), merges trains, and arranges bogies according to their distance from the source station.

## Features

* Bogie filtering after Hyderabad Junction (HYB)
* Train merging functionality
* Distance-based bogie sorting
* Handles journey completion scenarios
* Efficient implementation using Python data structures
